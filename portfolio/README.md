# Maria Francisca — Portfólio

Portfólio profissional de Maria Francisca, desenvolvedora web freelancer.

## Estrutura

- `index.html` — página principal
- `css/` — estilos, responsividade e animações
- `js/` — configuração, projetos e interações
- `images/` — imagens organizadas por finalidade
- `assets/` — recursos adicionais

## Execução local

Na pasta `portfolio`, execute `python -m http.server 8080` e acesse `http://localhost:8080`.

## Configuração

Edite `js/config.js` para informar WhatsApp e e-mail reais antes de publicar.

O projeto usa HTML, CSS e JavaScript puros, com Lucide Icons e Google Fonts via CDN.
